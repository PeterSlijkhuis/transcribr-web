Transcribr

Transcription with speaker detection, entirely in your browser. Nothing you pick leaves your computer. Desktop Chrome, Edge, Firefox or Safari.

🔒 100% local: your audio is never uploaded. Only the transcription engine itself (not your files) is downloaded, once, from Hugging Face.

0 = detect automatically. Know how many people speak? Enter it for much more accurate speakers.

Pick one if detection guesses wrong

These are the starting values for each file you add. Change them per file in the list below before you start. Each file shows a rough time, which gets more accurate once a file has finished on this device. The first run also downloads the model.

    ⚠️ Your files and transcripts live only in this browser tab. Closing or reloading it loses them, including files still in progress, so download what you need first.

        Which model should I pick?
        FastStandardAccurate
        Download, once32 MB190 MB514 MB (1.6 GB on a graphics card)
        Speed on a laptopSeveral times faster than the recordingAbout as long as the recordingTwo or more times longer than the recording on a processor; much faster on a graphics card
        MistakesMisses names, jargon and accents; drifts on noisy audioGood on clear speech in common languagesFewest. Holds up with accents, noise, crosstalk and less common languages
        Pick it forA quick rough draft, or an old or slow computerMost interviews and meetingsAnything you'll quote or publish, or hard audio

        All three are the same Whisper model at different sizes, so they share languages and features; bigger just means fewer mistakes and more waiting. Not sure? Start with Standard, and rerun a file on Accurate if names or words come out wrong. Speaker detection is the same whichever you pick.

        On a graphics card, Accurate uses Whisper large-v3-turbo, a newer and larger model that is usually more accurate still. It can't translate, so with Translate to English on, Accurate runs on the processor.
